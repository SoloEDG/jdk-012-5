# 双语无障碍讲解轨道 · 设计说明

## 1. 核心抽象：语义段落（Segment）

讲解不再按“秒数百分比”切字幕，而是以**语义段落**为最小单位。每件作品的讲解由若干语义段落组成，段落是双语对齐、字幕、语音、画面高亮、收听记录的共同锚点。

```ts
type Segment = {
  id: string;          // 作品内唯一，如 "a1#s2"
  zh: string;          // 原声（中文）文本
  en: string | null;   // 译文文本；null = 该段无译文
  highlight: string;   // 该段对应的画面焦点说明
  zhChars?: number;    // 估算时长用
};
```

- 中文与英文的同一段落共享同一个 `segment id`，但**各自拥有独立时间轴**：英文单词更多，段落自然更长。
- 全局位置 = “当前段落索引 + 段落内秒数”，不存在跨语言的绝对秒数映射。

## 2. 各自时间轴与段落对齐的取舍

- 每种语言按自身文本估算段落时长（中文按字数、英文按词数，再除以倍速）。
- 切换语言时**保留语义位置**：定位到同一段落索引，段落内进度归零，从新语言的该段开头重新播放；已结束的段落绝不重复念。
- 同一时刻只允许一条播放会话（session）。播放、切换语言、切换作品、自动进站都会生成或校验 session 令牌，过期异步回调（语音合成回调、下载回调、定时器）一律作废——这是“不串台”的总闸门。

## 3. 译文缺失与语音包下载的明确回退规则（段落级）

进入某段时按顺序裁定，结果以徽标明确告知用户：

1. 目标语言译文**存在**且目标语言语音包 `ready` → 目标语言语音 + 目标语言字幕（无徽标）。
2. 译文存在但语音包仍在下载/下载失败 → **原声语音** + 目标语言字幕，徽标「原声 · 译制语音下载中」。
3. 译文本身缺失（`en === null`）→ 原声语音 + 原声字幕，徽标「原声 · 本段无译文」。
4. 设备没有任何可用语音引擎 → 不出声，仅展示字幕，该段记为「只看过」，徽标「仅字幕」。

原声（中文）语音包视为本地始终就绪，因此任何情况下都有确定性回退，不会出现“没有声音也没有说明”的段落。

## 4. 倍速、拖动、无音频段落

- 倍速在播放中修改：时间轴立即按新倍速计时，当前段语音以新倍速重新起念，已念完的段落不回溯。
- 拖动进度条：按目标语言时间轴换算到段落。向前跳过的未完成段落**显式记为「已跳过」**；向后拖动不抹除既有收听记录。
- 拖到没有音频的字幕段：字幕与焦点高亮正常呈现，播放器显示「仅字幕（无音频）」，不冒充收听。
- 手动跳过/手动下一站：剩余段落全部记「已跳过」，不计入收听完成。

## 5. 诚实的收听记录

每个段落三种结局，互斥且持久化：

| 结局 | 含义 |
| --- | --- |
| `heard` 听过 | 段落自然播完，且确实有语音播出（含回退原声） |
| `watched` 只看过 | 段落走完，但全程无语音，仅阅读字幕 |
| `skipped` 已跳过 | 用户手动跳过/拖动越过，未消费内容 |

- 作品级：至少一段 `heard` 才算「听过」；只有 `watched` 没有 `heard` 为「只看过」。
- 个人回顾与参观回顾文件中分别列出三类数据，跳过不伪装成完成。

## 6. 主题导览的推进规则

- 导览仅在讲解**自然播完**（最后一段走到结尾）时自动进入下一站；自动进站通过 session 校验杜绝旧作品字幕残留。
- 每一站记录真实结局：`heard`（完整收听）/ `watched`（仅字幕看完）/ `skipped`（手动跳过）。
- 导览进度 = 非跳过完成站数 / 总站数；面板逐站展示三种标记。
- 手动「下一站」立即把当前作品未完成段落记为跳过，再步行前往下一站。

## 7. 恢复参观

导览与播放快照（作品、语言、段落索引、倍速、各段结局）持久化到 localStorage。重新打开时显示恢复条：

> 继续参观？当前语言：English；《无声的潮汐》还有 2 段未完成。

恢复后讲解处于**暂停**状态，由用户主动播放；也可选择重新开始（清空该作品的段落记录）。

## 8. 画面高亮联动

- 3D 场景中当前讲解作品的画框按节奏发出微光脉冲，其余画框复位。
- 右侧作品档案与字幕区同步显示当前段落的 `highlight` 焦点说明，并列出每段的收听状态。
- 高亮跟随语义段落，不跟随秒数；切换语言后高亮位置不变（段落对齐）。
